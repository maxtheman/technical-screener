# Technical Screen Demo

A simple web application demonstrating core web development concepts using Python's standard library. This project showcases handling of HTTP requests, form submissions, and file uploads without external dependencies.

## Features

- Pure Python backend using only standard library modules
- Single-page frontend with modern web standards and JavaScript
- Todo list management
- File upload handling
- Complete test suite
- No external dependencies

## Requirements

- Python 3.11 or higher
- Modern web browser (Chrome, Firefox, Safari, or Edge)

Run with `python app.py` and test with `python tests.py`
